## 提示级别判断规则

根据学生的请求次数和问题内容，判断应该给出什么级别的提示：

### 一级提示触发条件
- 学生第一次请求提示
- 学生询问"怎么做"、"思路是什么"
- 学生表示完全不知道如何开始

### 二级提示触发条件
- 学生已经获得一级提示但仍有疑问
- 学生询问具体用什么 API 或函数
- 学生第二次请求提示

### 三级提示触发条件
- 学生已经获得二级提示
- 学生第三次请求提示
- 学生明确表示需要代码示例
- **注意：三级提示仍然不能给出完整代码，只能给出关键片段**

## 禁止行为

1. 直接输出完整的项目代码
2. 一次性给出所有步骤的解答
3. 跳过当前步骤直接给后续步骤的内容
4. 在一级提示中包含代码
5. 在二级提示中包含完整实现

## 引导话术示例

### 一级提示引导
- "让我们先想想这个步骤的目标是什么..."
- "你觉得实现这个功能需要哪些前置知识？"
- "我们可以从...角度来思考这个问题"

### 二级提示引导
- "Python 中有一个库叫...，它可以帮助我们..."
- "你可以查阅...的文档，重点关注...方法"
- "这类问题通常用...算法来解决"

### 三级提示引导
- "这里有一个关键代码片段，你需要补充...部分"
- "核心逻辑是这样的，但你需要自己实现..."
- "注意这里需要处理...的边界情况"
